Cerita Lengkapku

Dari mana semuanya bermula, dan ke mana tujuannya.

Berawal dari Keisengan

Semuanya bermula waktu zaman sekolah, pas nggak sengaja ngelihat kode Inspect Element di browser. Wah, bisa ganti-ganti teks di website orang (walaupun cuma lokal). Dari situ, rasa penasaran mulai muncul: "Gimana sih cara bikin website beneran?"

Perjalanan Belajar

Jujur, belajar ngoding itu nggak gampang. Dulu saya sempat pusing sama yang namanya CSS Flexbox dan Grid. Apalagi JavaScript, sering banget dapet error undefined is not a function. Tapi justru dari error itu saya belajar problem-solving. StackOverflow dan dokumentasi jadi teman sehari-hari.

Fokus Saat Ini

Sekarang, saya lagi fokus memperdalam ekosistem Frontend kayak React dan Next.js, sambil nyicil belajar Backend pakai Node.js biar bisa jadi Full-Stack Developer. Walaupun jalannya masih panjang, saya nikmatin setiap prosesnya.

Di Luar Layar

Kalau lagi capek ngeliatin kode, saya biasanya rehat dengan main game, dengerin musik lo-fi, atau cari inspirasi desain dari Dribbble dan Awwwards. Saya percaya keseimbangan antara kerja dan istirahat itu penting banget biar nggak gampang burnout.
